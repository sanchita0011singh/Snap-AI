SnapAI – AI Powered Photography Web Portal
About

SnapAI is a web-based project made using Python and Django. It is designed to help photographers upload and share their photos, and users can easily search, view, and download images from the platform.

The main aim of this project is to create a simple and useful system where both photographers and users can interact in one place.

One special feature of this project is AI-based caption generation, which automatically creates captions for images. This helps in saving time and makes the content more meaningful.

Features
User registration and login
Photographer profile
Upload images (free and paid)
Search and download images
AI caption generation
WhatsApp communication
Feedback and rating
Admin panel for control
Technologies Used
HTML, CSS, Bootstrap, JavaScript
Python, Django
SQLite
How to Run
git clone https://github.com/sanchita0011singh/Snap-AI.git
cd snapai
pip install -r requirements.txt
python manage.py runserver
